# Symon Abok — DevOps Portfolio

A recruiter-focused portfolio presenting hands-on AWS, Kubernetes, Terraform, CI/CD and GitOps projects.

## Run locally

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run build
```

## Deploy to GitHub Pages

The Vite base path is configured for the `Portfolio` repository.

```bash
npm run deploy
```

The published site will be available at `https://symon30.github.io/Portfolio/`.
